# MechaniLink 🛠️

**An On-Demand Vehicle Repair and Spare Parts Delivery Platform**

MechaniLink is a unified web and mobile platform designed to transform the vehicle breakdown recovery experience. It connects stranded drivers with nearby freelance mechanics and auto-part stores, facilitating swift, transparent, and reliable on-the-spot repairs.

![Status](https://img.shields.io/badge/Status-In%20Development-orange)

## 🚀 Problem Statement

Vehicle breakdowns are stressful, inconvenient, and often dangerous. The current solution is fragmented:
- Drivers struggle to find reliable, available mechanics.
- The process of sourcing spare parts is slow and inefficient.
- There is a complete lack of price and service transparency.

MechaniLink solves this by creating a single, integrated ecosystem for all stakeholders.

## ✨ Key Features

### For Drivers 🚗
- **Instant Help:** Submit a service request with your location and vehicle issue.
- **Find Nearby Mechanics:** View profiles, ratings, and select the best mechanic for the job.
- **Transparent Process:** Track the mechanic's arrival and repair status in real-time.
- **Spare Parts Sorted:** Mechanics can order required parts to be delivered to your location.

### For Mechanics 🔧
- **Get More Jobs:** Receive real-time notifications for nearby service requests.
- **Build Your Profile:** Showcase your skills, experience, and tools to attract clients.
- **Efficient Parts Sourcing:** Search and order necessary parts from local stores directly through the app.
- **Earn Reviews:** Build your reputation with a built-in rating system.

### For Part Stores 🏪
- **Increase Sales:** Get direct orders from active repair jobs in your area.
- **Manage Orders:** Receive and confirm part requests through a simple web interface.

## 🛠️ Tech Stack

**Frontend:**
- React.js (Web Application)
- React Native (Mobile Application)

**Backend:**
- Node.js with Express.js
- JWT for Authentication

**Database:**
- PostgreSQL / MySQL

**Services & APIs:**
- Google Maps Platform (Geolocation & Places)
- Firebase Cloud Messaging (Push Notifications)
